# ===================================================================
#  DIALOGUE FILE  -  every line here becomes a yellow VHS subtitle.
#  You can make as many .txt files in this folder as you like
#  (one per chapter, one per room...). They are all read together.
#
#  [name]              starts a conversation. Play it from a script:
#                          Dialogue.play("name")
#  NAME: text          a subtitle. Speaker names in CAPITALS.
#  text                a subtitle with no speaker (sounds, thoughts...)
#  NAME: text | 4      keep this subtitle up for 4 seconds
#                      (without "| 4" the time is worked out from
#                      how long the line is)
#  one\ntwo            \n breaks the subtitle onto a second line
#  @wait 1.5           1.5 seconds with no subtitle
#  @event lights_off   tells your scripts "lights_off" happened
#                      (they listen with Dialogue.event)
#  # note              lines starting with # are ignored
# ===================================================================
